# ⚽ 12碼讀心戰 (Penalty Mind Game)

「門將會讀你心——你夠唔夠估佢唔到？」

一個專為手機及瀏覽器打造嘅純前端 12 碼心理對決遊戲。完全毋須安裝任何依賴、冇任何外聯 CDN，雙擊 `index.html` 即可於電腦或 iPhone / Android 手機流暢開波！

---

## 🎮 遊戲玩法簡介

比賽採用正規互射 12 碼規則，你與電腦各射 5 輪（打和就入突然死亡階段）：

### 1. 你主射（攻擊階段）
* 球門劃分成 **6 大區域**：
  * **左上 (TL)** / **中上 (TM)** / **右上 (TR)**
  * **左下 (BL)** / **中下 (BM)** / **右下 (BR)**
* 直接點擊球門任何一個位置起腳。
* **死角風險**：左上同右上角雖然角度刁鑽，但因難度極高，有約 **12% 機會射中門楣或飛過界**。
* **中間沒收**：射中下位置時，若門將留守中間（中下），會被極容易直接沒收。
* 每腳射完之後，畫面會即刻彈出 **「門將讀心透視」** 面板，解構門將當前對你 6 個方位嘅預測機率同信心度！

### 2. 你把關（防守階段）
* 輪到對手主射，對手射手會進行約 **1 秒嘅助跑動畫**。助跑嗰 1 秒唔可以撲。助跑完，先有 1.5 秒揀位。
* 若超時未作出決定，門將會留守中間（中下）。
* 電腦射手有真實踢法傾向（約 60% 偏向地波死角，20% 射中路，20% 抽上角）。

## 🧠 AI 門將讀心機制

本遊戲嘅 AI 門將具備自我學習能力，會隨住遊戲進行不斷進化：

1. **頻率統計 (Unigram)**：記錄你射門各個方位嘅全局偏好。
2. **前後連續習慣 (Markov Bigram)**：分析你「上一次射完 X，今次習慣轉射 Y」嘅轉向規律。
3. **二階規律 (Trigram)**：分析「連續兩腳之後嘅第三腳」套路。
4. **混合預測模型 (Interpolated Ensemble)**：
   $$P(Z) = w_0 \cdot \text{Prior}(Z) + w_1 \cdot P_{\text{freq}}(Z) + w_2 \cdot P_{\text{bigram}}(Z \mid S_{t-1}) + w_3 \cdot P_{\text{trigram}}(Z \mid S_{t-2}, S_{t-1})$$
5. **小量隨機擾動**：門將以高機率撲向最高信心方位，但保留少量隨機性，避免過於機械化。
6. **持久化記憶 (LocalStorage)**：門將記憶會自動儲存於瀏覽器，跨場次持續學習。如果想令門將重回白紙狀態，可以隨時點擊 **「重置記憶」**。

## 📊 賽後統計與可預測度

完場後會提供專業賽後心理剖析：
* **可預測度 (Predictability Score 0–100%)**：
  基於門將學習之前後腳轉向規律（Markov Bigram）計算條件 **Shannon 熵 (Shannon Entropy)**：
  $$H = H(\text{next} \mid \text{last}) = -\sum_{i=1}^{6} p(Z_i \mid S_{t-1}) \log_2 p(Z_i \mid S_{t-1}), \quad H_{\max} = \log_2(6) \approx 2.585$$
  $$\text{可預測度} = \left(1 - \frac{H}{H_{\max}}\right) \times 100\%$$
  （若歷史不足則平滑退回全局頻率熵）
  * **0–20%**：頂級讀心大師 · 完全估唔到（毫無破綻，門將只能靠估）
  * **20–40%**：難以捉摸 · 射法多變
  * **40–65%**：攻守兼備 · 飄忽不定
  * **65–85%**：明顯偏好 · 露出破綻
  * **85–100%**：極易捉路 · 習慣定型（門將瞌埋眼都撲到）
* **累計射門熱點圖 (Heatmap)**：視覺化展示你喺 6 個區域嘅出腳比例。
* **門將讀心命中率** vs **你嘅撲救成功率**。

## 🚀 執行與測試

### 1. 開啟遊戲
直接雙擊開啟 `index.html`，或用任何本地 HTTP 伺服器啟動：
```bash
# 例如用 Python 啟動（非必須，直接點開 index.html 亦可）
python3 -m http.server 8000
```
或直接用 Safari / Chrome / Firefox 開啟 `index.html`。

### 2. 執行預測模型單元測試
本項目將預測核心演算法獨立於 `model.js`，可用 Node.js 進行純邏輯測試：
```bash
node tests/model.test.js
```
測試涵蓋：
* 初始分佈均勻性與 0 預測度測試
* 連續 10 次重複射門學習測試（最高機率收斂）
* 交替規律（TL ➔ BR ➔ TL ➔ BR）N-gram 預測測試
* Shannon 熵可預測度高低邊界測試
* 機率總和恆為 1.0 驗證
* 撲救方位加權選取測試
* 狀態儲存與匯出/還原測試
