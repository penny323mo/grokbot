# 盤口實驗室 (odds-lab) — 專業足球模型與盤口深度量化工具

為足球盤口愛好者量身打造嘅專業級網頁應用程式。集結 **Dixon–Coles 泊松預測模型**、**亞洲讓球盤四份一盤深度概率拆解**、**收市值（CLV）走勢追蹤**、**步進式（Walk-forward）量化策略回測** 及 **凱利注碼計算**，專為手機瀏覽（iPhone 390px）深度優化，支援五大歐洲聯賽（英超、西甲、意甲、德甲、法甲）。

---

## 🌟 核心功能分頁

### 1. ⚽ 對賽分析 (Match Lab)
- **自選對賽球隊**：透過底部抽屜（Bottom Sheet）支援以香港粵語官方譯名搜尋並選擇 2026-27 當季所有參賽球隊；提供一鍵對調主客隊功能。
- **本週即將開賽輪播**：預先載入最新賽程（`fixtures.csv`），一鍵載入賽事即時賠率。
- **預期入球數 (xG)**：基於球隊攻防實力指數，即時計算雙方預期進球（$\lambda_{\text{主隊}}, \lambda_{\text{客隊}}$）及攻防對比量表。
- **獨贏及和局 (1X2) 深度分析**：展示模型公平賠率 vs 莊家開盤賠率、剔除抽水後嘅真實勝率、模型值博優勢（Edge %），當優勢超越門檻即顯示發光「⭐ 值博」標籤。
- **波膽概率熱力圖 (7×7)**：0 至 6 球全部比分矩陣，動態色彩漸層標註最可能比分，點擊任意比分格可即時查看精確勝率與模型公平價。
- **大細波 (O/U) & 兩隊入球 (BTTS)**：支援 1.5 / 2.5 / 3.5 球即時切換與公平賠率計算。
- **亞洲讓球盤深度拆解**：$-2.00$ 至 $+2.00$ 球（每 0.25 檔位），細拆「贏全 / 贏半 / 走盤 / 輸半 / 輸全」概率，精準標記「模型公平盤口」與「莊家開出盤口」；設有 ⓘ 按鈕彈出四份一盤廣東話規則速查手冊。
- **凱利注碼計算機 (Kelly Criterion)**：可自選投注市場（獨贏、大細波、讓球盤），自動代入模型勝率與賠率，計算正期望值（EV %）及建議下注金額（支援 0.1x 至 1.0x 分數凱利縮放，防止過度下注）。

### 2. 📈 盤口走勢 (Market Movement & CLV)
- **球隊近期賽事追蹤**：查詢球隊近 10 場比賽嘅開市至收市獨贏水位（升水 / 降水箭嘴）及讓球盤跳檔紀錄。
- **收市值（CLV）每場結算**：計算假若按開市價下注，對比最終收市主流頂級莊家公平價之收市值（Closing Line Value）。
- **聯賽市場效率大數據**：統計聯賽平均收市抽水率、讓球盤跳盤比例、受追捧方（熱錢流入方）贏盤率。
- **收市值深度教學**：詳細解構點解「長期買得贏收市價，就代表搵到真正嘅正期望值（+EV）」。

### 3. 🧪 策略回測 (Walk-forward Backtest)
- **嚴謹步進式回測**：保證回測每場賽事時，模型僅使用比賽日前嘅歷史賽果進行擬合，絕無「偷睇未來數據」。
- **多元回測參數**：可自選聯賽（單一聯賽或五大聯賽綜合）、回測賽季（2025-26 完整賽季 / 2026-27 當前賽季 / 兩季綜合）、市場（1X2 / 讓球盤 / 大細波 2.5）、開市或收市賠率、平注或凱利注碼、值博門檻滑桿（1% 至 10%）。
- **Canvas 資金曲線圖表**：純 HTML5 Canvas 動態繪製資金進展圖，清晰標註 100 單位基準線與半透明漸變填充。
- **關鍵量化績效指標**：總下注場數、勝率（Hit Rate %）、淨利潤（Profit Units）、投資回報率（ROI %）、最大回撤（Max Drawdown %）、平均 CLV 及擊敗收市價比例。
- **五大聯賽分項明細表**：一覽英超、西甲、意甲、德甲、法甲各項獨立策略回測數據。

### 4. 🛡️ 球隊戰力 (Teams & Form)
- **2026-27 現時積分榜**：根據當季歷史戰果即時動態計算聯賽榜，包含賽、勝、和、負、得、失、淨勝球、積分及近五場狀態藥丸（勝 / 和 / 負）。點擊任意球隊即可排入「對賽分析」。
- **模型攻防戰力榜**：展示 Dixon-Coles 擬合出之進攻力量（$\alpha$）、防守系數（$\beta$）及淨評分。設有一鍵「設為主隊」及「設為客隊」跳轉按鈕。

### ⚙️ 偏好設定 (Settings)
- 點擊頂部齒輪圖標開啟設定抽屜，支援設定值博率門檻（預設 3.0%）、凱利係數（預設 0.25x）、時間衰減半衰期（預設 180 日）、抽水剔除演算法（比例均攤法 / 指數冪次法）、總本金。
- 所有設定即時持久化於瀏覽器 `localStorage`，重新整理網頁依然保留。

## 📐 數學模型原理

1. **Dixon–Coles 泊松回歸模型**：
   $$\lambda_{\text{home}} = \exp(\mu + \text{home\_adv} + \alpha_{\text{home}} - \beta_{\text{away}})$$
   $$\lambda_{\text{away}} = \exp(\mu + \alpha_{\text{away}} - \beta_{\text{home}})$$
   配合低比分（0-0, 1-0, 0-1, 1-1）之 $\tau$ 相關性修正（$\rho \approx -0.05$）與時間衰減權重 $w = \exp(-\Delta t \cdot \ln 2 / T_{\text{half}})$。
2. **莊家抽水剔除演算法**：
   - **比例均攤法 (Proportional Method)**：$p_i = (1 / o_i) / \sum_j (1 / o_j)$。
   - **指數冪次法 (Power Method)**：求解數值 $k$ 使 $\sum_j (1 / o_j)^k = 1$。
3. **亞洲讓球盤四份一盤拆分與零期望值公平賠率**：
   - 四份一盤（如 $-0.75$）拆為一半注碼落 $-0.5$、一半注碼落 $-1.0$。
   - 求解使 $E[\text{Profit}] = 0$ 之賠率 $O_{\text{fair}}$。
4. **收市值 (CLV)**：
   $$\text{CLV} = \frac{O_{\text{taken}}}{O_{\text{close\_fair}}} - 1 = (O_{\text{taken}} \times P_{\text{close\_fair}}) - 1$$

## 🧪 測試與驗證

### 1. 執行單元數學與數據完整性測試
```bash
node --test tests/
```
包含 9 項測試：
- Poisson / Dixon-Coles 比分矩陣總和等於 1（誤差 $\pm 10^{-9}$），概率非負，1X2 總和等於 1。
- 亞洲讓球盤檔位（0, -0.25, -0.5, -0.75, -1, +0.25, +1.25）各種分差下之精確派彩乘數。
- 讓球盤五大賽果拆分總和為 1，公平賠率之期望值 EV $\approx 0$。
- 凱利公式計算（例如 $p=0.55, \text{odds}=2.0 \implies 0.10$）、無優勢時歸零及分數縮放。
- 抽水剔除之真實概率總和為 1。
- CLV 算法驗證。
- `data/data.js` 於 Node VM 載入正常、五大聯賽 2026-27 當季球隊數目符合 20/18 隊、比賽比分合法。
- 回測引擎於數據切片上平穩運行並返回有限實數。

### 2. 執行無頭瀏覽器 (Puppeteer) E2E 驗證
```bash
node test_e2e.js
```
自動啟動本地伺服器、以 iPhone 390×844 視窗開啟、驗證無橫向滾動（scrollWidth == 390）、控制台 0 錯誤、四大分頁點擊流暢、截圖儲存於 `screenshots/`。
