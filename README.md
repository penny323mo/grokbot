# ⚽ 12碼讀心戰 (Penalty Mind Game v2)

「向球門揮動手指射門——你夠唔夠膽呃過 AI 門將？」

專為 iPhone Safari (390×844) 與現代瀏覽器打造嘅 **3D 擬真點球心理戰遊戲**。
告別舊版點擊 6 格方塊嘅平淡玩法，全新升級為 **Three.js 3D 球場視角**、**手指滑動起腳（力道、弧線、香蕉球旋轉）**、**關節動態門將撲救空間計算**、**Web Audio 擬真合成音效** 及 **深度神經感知 AI 讀心模型**！
零外部 CDN 依賴、支援離線運行、無任何構建步驟。

## 🎮 遊戲玩法與特色

### 1. 擬真 3D 滑動射門 (Swipe-to-Shoot)
* **起腳方向**：手指於屏幕下方向上滑動，直接映射真實球門空間位置。
* **球速與力度**：滑動速度（px/ms）直接決定球速（18 – 32 m/s，約 65 – 115 km/h）。若滑動過於猛烈（力度 > 92%），有機會抽高飛過門楣出界！
* **香蕉波旋轉 (Magnus Effect)**：手指滑動帶有弧度（微彎曲），足球會產生側旋，受 Magnus 氣動力影響於空中畫出香蕉弧線直奔死角！
* **彈道物理運算**：內建 120 Hz 數值積分，包含空氣阻力、重力、香蕉球側向加速度、草地彈跳與門柱門楣金屬回彈。
* **新手輔助線與幽靈手教學**：首兩腳提供虛線預測彈道與動態手勢引導（「向球門撥一下射門，撥快啲大力啲，撥彎啲會轉彎」），上手即熟悉。

### 2. 物理撲救體積判定 (Goalkeeper Reach Volume)
* 門將擁有完整 3D 人體關節骨骼層次與動態機（熱身準備、深蹲 Set 姿勢、極限飛撲、中路封阻、撲出歡呼、失球懊惱）。
* **非擲骰判定**：撲救成功完全依賴門將身體與手套撲救體積於皮球過白界瞬間嘅幾何空間碰撞；只要角度夠刁鑽、波速夠快（如抽向死角），即使門將撲向正確方向亦無法挽救！
* **沒收 vs 拍出**：極速重炮撲中會向外彈出解圍（Parry），平緩球路則穩穩沒收（Catch）。

### 3. AI 門將讀心大腦
門將會即時記錄你嘅射門方位、前後連招套路（Markov Bigram & Trigram），隨住賽事推進不斷進化：
* **局中讀心顯現**：每一球射出後，球門前方會浮現 3D 紫色光環標記門將預判落點，並顯示即時心理信心（例如「門將估你射：左下（信心 47%）」）。
* **可預測度分析 (Predictability Score)**：
  * 當射門次數 `< 8` 次時，顯示「數據不足」，提示球員累積習慣數據。
  * 達標後以 Laplace 平滑條件 Shannon 熵計算（0 – 100%）。多變隨機分佈可獲得 `< 30%` 極低可預測度評價，反之慣性規律將被無情看穿！

### 4. 點球大戰與突然死亡 (Match Flow)
* 雙方各射 5 輪點球，點球點計分板即時記錄得失球。
* 若雙方於 5 輪內提前達成數學鎖定勝局（提前奪冠），賽事自動結束。
* 若 5 輪打和，即時進入 **突然死亡階段 (Sudden Death)**，每輪一球定勝負！

### 5. 多感官回饋與音效 (Juice & Web Audio)
* **近門慢動作 (Slow-Mo)**：足球接近球門 3 米範圍自動切換 0.3x 慢動作視角，扣人心弦。
* **金屬中柱 clang 與球網沙沙聲**：以 Web Audio 合成金屬諧波、破網白噪聲脈衝、沉悶起腳聲及群眾歡呼浪潮。
* **入波慶祝**：球網真實物理凹陷變形、鏡頭震動與彩色紙碎（Confetti）漫天飛舞。
* **無障礙支援**：偵測系統 `prefers-reduced-motion`，自動停用慢動作與鏡頭晃動。

## 🚀 本地執行與測試

### 1. 開啟遊戲
直接於瀏覽器雙擊開啟 `index.html`，或用本地 HTTP 伺服器啟動：
```bash
# 例如使用 Python 本地伺服器
python3 -m http.server 8000
```
或直接於 Safari / Chrome 點開 `index.html`。

### 2. 執行單元測試
本項目包含完整純邏輯單元測試套件，完全毋須瀏覽器或外部依賴：
```bash
# 執行所有測試
node tests/model.test.js && node tests/shot.test.js && node tests/keeperAI.test.js && node tests/input.test.js
```
測試覆蓋：
1. `tests/model.test.js` (14 題)：N-gram 規律學習、機率歸一化、`< 8` 次數據不足守衛、5 方位多變低可預測度 (< 30) 驗證。
2. `tests/shot.test.js` (6 題)：直線向上滑動映射、滑動速度與球速縮放、香蕉球 Magnus 彎曲側移、超限大力飛過界、6 區方位判定、球門過白界後繼續直入網底彈道。
3. `tests/keeperAI.test.js` (6 題)：門將預判反應決策、手套撲救範圍判定、反向飛撲漏波、極限死角高速破門、重炮拍出 vs 慢波沒收、軀幹身體 Capsule 幾何撲救判定。
4. `tests/input.test.js` (3 題)：手機 TouchEvent 滑動主射、PointerCapture 生命週期鎖定、屏幕底部 75% 起腳區域檢測。
