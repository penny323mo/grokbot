# ⚽ 12碼讀心戰 (Penalty Mind Game v2)

「向球門揮動手指射門——你夠唔夠膽呃過 AI 門將？」

專為 iPhone Safari (390×844) 與現代瀏覽器打造嘅 **3D 擬真點球心理戰遊戲**。
告別舊版點擊 6 格方塊嘅平淡玩法，全新升級為 **Three.js 3D 球場視角**、**手指滑動起腳（力道、弧線、香蕉球旋轉）**、**關節動態門將撲救空間計算**、**Web Audio 擬真合成音效** 及 **深度神經感知 AI 讀心模型**！
零外部 CDN 依賴、支援離線運行、無任何構建步驟。

---

## 🎮 遊戲玩法與特色

### 1. 攻守輪換對決 (Both Sides Shootout)
* **主射回合 (Player Strikes)**：向前滑動射門，支援力量縮放、左右香蕉波側旋弧線，太大力（> 92%）會抽高過楣。
* **把關回合 (Keeper Mode by Swipe)**：
  * 取代舊版電腦過場動畫，輪到你扮演門將！
  * 3D 擬真射手人形（`src/taker.js`）流暢助跑起腳。
  * **時機窗口至關重要**：若玩家過早起跳飛撲（> 250ms 前），射手會即刻洞悉並推射相反空門！於起腳瞬間（±200ms）滑動即可觸發極速飛撲。
  * **射手 AI 讀心大腦 (`src/takerAI.js`)**：獨立學習玩家嘅撲救習慣（頻率與二連招規律），專攻你撲救盲區與死角！

### 2. 心理戰預警與廣東話垃圾話 (Mind-Game Tells & Taunts)
* **門將身體重心與眼神預警**：
  * 開波前門將會於球門前前後移位、向某一側傾斜身體（依難度設定包含真實提示與心理欺騙 Bluff）。
  * 於「難」與「地獄」模式中更開啟視線眼神凝視提示（Eye-line Gaze Hint）！
* **香港地道廣東話垃圾話 (`src/taunts.js`)**：
  * 內建超過 20 句（共 33 句）原汁原味港式對白氣泡（例如「又係左下？我睇穿你喇！」、「咁早撲定？多謝你讓半邊門畀我！」、「好反應！下次我抽大力啲睇你救唔救到！」），雙方攻守互相挑釁心理戰。

### 3. 場景內 3D 6區讀心光環 (In-Scene 3D Mind-Reading Reveal)
* 每一球射門/撲救完成後，球門前方 6 個區域（左上、中上、右上、左下、中下、右下）直接浮現 **3D 半透明機率光環與百分比標籤**。
* **落點與撲救標記**：金色光環標記足球實際過白界穿透點，青色光環標記門將手套撲救涵蓋點，直觀展現毫釐之差！

### 4. 決勝球電視轉播慢動作重播 (Slow-Motion Replay)
* 於奠定勝局嘅決勝球（Clinch 或突然死亡），自動切換為 **側向電視轉播機位 (Broadcast Side Angle)**。
* 以 0.25x 超慢動作播放入波或神撲，屏幕上方顯示 `🔴 重播 (REPLAY)` 水印與 `跳過 ➔` 快速跳過按鈕。

### 5. 四級難度體系 (Difficulty Levels)
* 於標題畫面自由切換：
  * 🟢 **易 (Easy)**：門將反應較慢、撲救範圍較細，90% 給予真實提示。
  * 🟡 **中 (Medium)**：標準模式，具備正常讀心判斷與適度虛實試探。
  * 🟠 **難 (Hard)**：門將反應迅捷、撲救範圍廣闊，真假動作並用，開啟眼神視線預警。
  * 🟣 **地獄 (Hell)**：門將預判神準極速撲救，狂出假動作，射手連環直抽死角！
* 選擇自動持久化儲存於 `localStorage`。

### 6. 擬真 3D 滑動射門 (Swipe-to-Shoot)
* **起腳方向**：手指於屏幕下方向上滑動，直接映射真實球門空間位置。
* **球速與力度**：滑動速度（px/ms）直接決定球速（18 – 32 m/s，約 65 – 115 km/h）。若滑動過於猛烈（力度 > 92%），有機會抽高飛過門楣出界！
* **香蕉波旋轉 (Magnus Effect)**：手指滑動帶有弧度（微彎曲），足球會產生側旋，受 Magnus 氣動力影響於空中畫出香蕉弧線直奔死角！
* **彈道物理運算**：內建 120 Hz 數值積分，包含空氣阻力、重力、香蕉球側向加速度、草地彈跳與門柱門楣金屬回彈。
* **新手輔助線與幽靈手教學**：首兩腳提供虛線預測彈道與動態手勢引導（「向球門撥一下射門，撥快啲大力啲，撥彎啲會轉彎」），上手即熟悉。

### 7. 物理撲救體積判定 (Goalkeeper Reach Volume)
* 門將擁有完整 3D 人體關節骨骼層次與動態機（熱身準備、深蹲 Set 姿勢、極限飛撲、中路封阻、撲出歡呼、失球懊惱）。
* **非擲骰判定**：撲救成功完全依賴門將身體與手套撲救體積於皮球過白界瞬間嘅幾何空間碰撞；只要角度夠刁鑽、波速夠快（如抽向死角），即使門將撲向正確方向亦無法挽救！
* **沒收 vs 拍出**：極速重炮撲中會向外彈出解圍（Parry），平緩球路則穩穩沒收（Catch）。

### 8. 球場視覺打磨與清晰度 (Visual Polish)
* **實體混凝土階梯看台**：球門後方建立 10 級實體混凝土階梯看台（Terrace risers），觀眾直接立於階梯上歡呼躍動。
* **球門後方滾動 LED 廣告牌**：動態電子廣告牌循環播放「⚽ 12碼讀心戰」與「⚡ AI 讀心大對決」。
* **放大足球半徑**：調校半徑至 0.135m，確保於 iPhone 390×844 手機窄芒上起腳軌跡清晰銳利。

## 🚀 本地執行與測試

### 1. 開啟遊戲
直接於瀏覽器雙擊開啟 `index.html`，或用本地 HTTP 伺服器啟動：
```bash
python3 -m http.server 8000
```
或直接於 Safari / Chrome 點開 `index.html`。

### 2. 執行單元測試
本項目包含完整純邏輯單元測試套件（共 7 套 58 題），完全毋須瀏覽器或外部依賴：
```bash
# 執行所有測試
node tests/model.test.js && node tests/shot.test.js && node tests/keeperAI.test.js && node tests/input.test.js && node tests/difficulty.test.js && node tests/takerAI.test.js && node tests/taunts.test.js
```
測試覆蓋：
1. `tests/model.test.js` (14 題)：N-gram 規律學習、機率歸一化、`< 8` 次數據不足守衛、5 方位多變低可預測度 (< 30) 驗證。
2. `tests/shot.test.js` (6 題)：直線向上滑動映射、滑動速度與球速縮放、香蕉球 Magnus 彎曲側移、超限大力飛過界、6 區方位判定、球門過白界後繼續直入網底彈道。
3. `tests/keeperAI.test.js` (6 題)：門將預判反應決策、手套撲救範圍判定、反向飛撲漏波、極限死角高速破門、重炮拍出 vs 慢波沒收、軀幹身體 Capsule 幾何撲救判定。
4. `tests/input.test.js` (3 題)：手機 TouchEvent 滑動主射、PointerCapture 生命週期鎖定、屏幕底部 75% 起腳區域檢測。
5. `tests/difficulty.test.js` (3 題)：4 級難度單調遞增參數階梯、不分大小寫與無效輸入退回、眼神提示僅限高難度驗證。
6. `tests/takerAI.test.js` (4 題)：射手 AI 學習玩家撲救習慣並避開防守、及時懲罰過早起跳撲救、地獄難度極限死角重炮、撲救機率歸一化。
7. `tests/taunts.test.js` (22 題)：廣東話垃圾話對白庫超過 20 句（33 句）驗證、全部類別對白提取、提示誠實度分佈驗證、眼神提示狀態。
