氣象資料來源與條款

1. RainViewer 雷達拼圖（非澳門氣象局官方圖）

雷達回波拼圖由 RainViewer 提供，每約 5 分鐘更新一次。色階採用 Universal Blue 階梯雨量圖式（非視頻遊戲彩虹色階）。若資料時間超過 20 分鐘，系統會提示資料可能已過時。

RainViewer API 條款 · rainviewer.com

2. Open-Meteo 模式預測（非官方觀測）

未來兩小時點位降雨預報（8 個 15 分鐘步長）來自 Open-Meteo 氣象數值預測模式。本工具僅將其用作推算降雨開始或停止之時間參考，絕非澳門地球物理氣象局官方實況觀測。

Open-Meteo 條款與授權

3. 澳門地球物理氣象局 (SMG) 官方觀測

嘗試直接讀取氣象局官方 XML 實況雨量（c_actualweather.xml）。該端點若未開放跨域資源共享（CORS），現代瀏覽器基於同源安全政策無法直接讀取。若讀取失敗，本應用坦白說明「澳門地球物理氣象局官方雨量未能喺瀏覽器讀取（來源無開放跨域）」，絕不捏造虛假官方 0 毫米數據。

4. 香港天文台 (HKO) 官方雨量

鄰近香港站（如離島區 / 屯門）雨量來自香港天文台開放數據，透過 DATA.GOV.HK 條款使用，僅供珠江口東岸參考（非澳門觀測）。
