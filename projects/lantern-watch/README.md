# 燈籠小鎮守夜人 (Lantern Watch) 🏮

> 戰棋加卡牌嘅溫馨守夜冒險：排兵佈陣、砌牌組，守住小鎮燈籠！

專為 iPhone（390×844 視口）與現代移動端設計嘅輕度 Roguelike 戰棋卡牌遊戲。無廣告、無內購、無需網絡，純本地靜態運行。

---

## 📖 故事背景 (Story)

每逢夜幕降臨，濃霧從山谷蔓延而至，迷霧中浮現各種淘氣又危險嘅霧怪，試圖熄滅小鎮南街嘅三盞古老燈籠。
作為小鎮嘅守夜人，你將手持靈符卡牌，指揮身懷絕技嘅可愛守護者（貓巡邏員、茶師傅、燈籠匠、稻草人等），喺 5×6 方格棋盤上推怪、走位、激發陣法共鳴，守護小鎮黎明！

---

## 🎮 玩法特色 (Key Features)

1. **戰棋 × 卡牌雙核心 (Tactics & Deckbuilding)**：
   - 每回合 3 點能量，抽取手牌。
   - 包含【召喚】、【指令】、【法術】與【燈火】四大卡牌類別。
   - 棋盤地型豐富：草地、水池（推怪入水受額外碰撞傷）、竹林（掩體減傷）、石燈籠台（增強射程與破霧）。
2. **清晰敵方意圖 (Visible Next-Turn Intents)**：
   - 告別盲猜！每隻霧怪頭頂標註下回合意圖：紅色鎖定目標方格、攻擊傷害數值、前進虛線路徑。
   - 善用狸貓魔術師嘅擊退、稻草人嘅嘲諷、小龍嘅直線噴火，化解滅燈危機！
3. **陣法共鳴與相鄰增益 (Tags & Synergies)**：
   - 守護者自帶「光」、「毛」、「守」、「術」四大靈魂標籤。場上集齊同標籤雙人，即可激發強大共鳴（如雙守加護甲、雙毛提速、雙光灼燒回血）。
   - 茶師傅相鄰回合末回血、燈籠匠相鄰加射程，站位極具深度。
4. **手機端純點擊流暢操作 (iPhone 390px Tap-Only)**：
   - **點擊手牌**：卡牌浮起，棋盤上合法格子泛起金色光芒。
   - **點擊格子**：精準施放！再次點擊卡牌即取消選擇。
   - **點擊單位**：隨時喚出底部詳細資訊抽屜（屬性、技能、背景故事）。
   - **隨時悔棋**：每回合提供 1 步悔棋（悠閒難度無限悔棋），出錯手無壓力。
   - 所有點擊熱區 $\ge 44\times 44\text{px}$，結束回合按鈕穩居拇指盲操黃金區。
5. **休閒小鎮建設 (Cozy Town Meta-Progression)**：
   - 冒險贏輸皆可賺取「星燈」，喺主選單建設小鎮建築（守夜小亭、飛信驛站、蓮池樂坊、狐仙小祠等）。
   - 永久解鎖新守護者（鶴郵差、蛙樂師、狐巫女、熊麵包師）、全新起始流派牌組與被動增益。
6. **多重難度與進階挑戰 (Difficulties & Ascension 1–5)**：
   - **🍵 悠閒 (Relaxed)**：燈籠 4 血，敵人傷害降低，無限步數悔棋，品茶守夜。
   - **🏮 標準 (Standard)**：標準戰棋博弈，耐玩平衡。
   - **⚔️ 挑戰 (Challenging)**：燈籠 2 血，增援增加，步步驚心。
   - 首次通關解鎖 **進階 1–5 (Ascension)**：濃霧蔓延、凶靈狂暴、殘燭難續等特色詞條。

## 🛠️ 工程架構與自動化測試

- **純模組化引擎**：
  - `js/engine/rng.js`: 確定性種子隨機數。
  - `js/engine/board.js`: 5×6 方格數學與擊退碰撞物理。
  - `js/engine/battle.js`: 戰鬥狀態機、出牌結算與勝負判定。
  - `js/engine/ai.js`: 敵方意圖預判路徑演算法。
  - `js/engine/town.js`: 小鎮元進程、存檔與中途進度安全恢復。
  - `js/engine/bot.js`: 具備完整自主決策能力嘅 AI 測試機器人。
- **測試命令**：
  ```bash
  npm test
  # 或 node tests/rules.test.mjs && node tests/intents.test.mjs && node tests/save_load.test.mjs && node tests/bot_run.test.mjs
  ```
- **截圖腳本**：
  ```bash
  node scripts/capture_screenshots.mjs
  ```
  在 390×844 視口下截取 `screenshots/r1/` 全部 7 幅高精度遊戲截圖，保證 0 控制台報錯（Console Errors = 0）。
