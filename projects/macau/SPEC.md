# 行澳門

同一個應用，`projects/macau/`。計劃網址仍然係 https://penny323mo.github.io/grokbot/projects/macau/ ，未當已上線。

併入：點去同行程巴士、斜路高度、出門泊車再行、就近設施、天色嘅模式天氣、雨勢雷達、潮候模式水位、地勢地標高度。獨立頁網址保留。

讀唔到：地球物理氣象局 XML（2026-11-18 再探 HTTP 200，無 CORS，唔做代理）、交通事務局即時位置同官方車位、天文台即時潮汐、地勢立體頁（因為原頁用咗 MapLibre 4.7 冇嘅檢查）。遊戲項目冇併入。

同一個起點、終點同定位，放喺一張夠大嘅澳門地圖上。行路用 FOSSGIS 行人路徑，比較較平同較短，附高度剖面同樓梯指示。巴士用交通事務局網站 JSON 嘅下載路線站位，唔當即時到站。

計劃網址（未當已上線）：https://penny323mo.github.io/grokbot/projects/macau/

`projects/dim-heoi/` 同 `projects/ce-lou/` 嘅獨立網址冇改。地圖庫、字型同巴士下載檔用相對路徑指去嗰兩個目錄，呢度唔再複製一份。

## 預設

起點議事亭前地（22.1938271, 113.5399903，OpenStreetMap／Nominatim，2026-11-17 記錄）。終點東望洋燈塔（22.1964359, 113.5497062，同一記錄）。定位失敗、拒絕、超時或者唔喺澳門，都保持呢個起點，並寫明原因。模擬定位會標「模擬定位」。
