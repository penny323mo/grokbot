### 2. 首頁：「未來三日實盤」 (Live Fixtures Home Page)
- **首頁即實盤**：
  - 首頁即進入 `#tab-fixtures`（底部導航「🔥 實盤」設為預設 Active 標籤）。
  - 自動提取五大聯賽即將開賽賽程，支援頂部聯賽晶片篩選（「全部」及各聯賽切換）。
- **雙重精確時區過濾**：
  - **構建期**：`build_data.py` 相對構建日期保留 `today - 1` 至 `today + 5` 餘裕窗口。
  - **客戶端**：`js/model.js` 實現 `filterFixturesInWindow(fixtures, now, 72)`，動態過濾已開賽場次；`convertUKToMacau` 透過 `Intl.DateTimeFormat` 正確處理英國夏令時間（BST, UTC+1, +7h）與冬令時間（GMT, UTC+0, +8h），包括 10 月最後一個星期日冬令換日時段。
- **賽程卡片與分析維度**：
  - 依澳門日期分組展示（「今日 10月25日 (星期日)」、「聽日 10月26日 (星期一)」等）。
  - **1X2 獨贏**：主客和開盤賠率 vs 模型公平價 vs 值博率（正期望值發光標記 `🔥 +X.X% 值博`）。
  - **2.5 球大細波**：大波 / 細波開盤賠率 vs 模型公平價 vs 值博率。
  - **亞洲讓球盤 (AH)**：莊家開盤讓球檔位與賠率 vs 模型公平盤口與公平水位。
  - **讓球盤剖析**：模型公平盤與莊家開盤深度對比，輸出廣東話策略解說（如「莊家讓步偏淺，主隊讓球上盤具值博空間」）及勝負概率拆解。
  - **凱利注碼建議**：全場正期望值最佳注碼推薦及凱利建議注碼比例與金額（若無正期望值則提示觀望略過）。
  - **深入盤口分析聯動**：一鍵「深入盤口分析 →」即時無縫跳轉至「對賽」標籤頁，載入該賽事之 7×7 波膽熱力圖、讓球盤完整四份一盤檔位及凱利計算機。
- **空狀態與更新時間戳記**：
  - 視窗內無賽程時顯示地道廣東話空狀態：`「未來三日暫時冇賽程／賠率，football-data 通常逢星期二、五更新」`。
  - 首頁與頂部徽章明確顯示 `「數據更新於 YYYY-MM-DD HH:mm（澳門時間）」`，動態解析自 `build_data.py` 產出之 `generatedAt` UTC ISO 時間戳。

### 3. 自動化數據抓取腳本 (`scripts/fetch_data.sh`)
- 支援下載五大聯賽 `2526`、`2627` 共 10 個聯賽 CSV 及 `fixtures.csv`。
- 注入 User-Agent `Mozilla/5.0`，具備最大 4 次指數退避重試機制。
- 嚴格校驗下載檔案之非空性及 CSV 標頭格式，若失敗則立即報錯退出。

### 4. GitHub Actions CI/CD 工作流 (`.github/workflows/update-data.yml`)
- 排程觸發：每天 UTC 22:00 與 10:00（即澳門時間 06:00 與 18:00），並支援手動 `workflow_dispatch`。
- 權限配置：`contents: write`, `pages: write`。
- 運行環境：Ubuntu Latest, Python 3.12, Node.js 20。
- 流程：執行 `fetch_data.sh` → `python3 build_data.py` → `node --test tests/`。
- 變更提交流程：若 `data/data.js` 有變更，以 `github-actions[bot]` 提交並推送 `data/data.js`。
- 觸發 Pages 構建：推送後調用 `gh api -X POST repos/${{ github.repository }}/pages/builds`，若失敗輸出警告但不中斷工作流。
